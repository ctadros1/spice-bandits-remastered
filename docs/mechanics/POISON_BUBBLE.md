During lift, age increments by float32(dt_ms/500). Its new value contributes to the second clock denominator: progress += float32(dt_ms/float32(500+age)). A supplied moving actor updates target+0x24/+0x28 from actor+0x190/+0x194 only while follow-target bit0 is set. Missing actors retain the last target. Explode receives six0.05s updates before setting its position to currentY-15; ExplodeSpray gets currentY-5 before six warmups. Only a successful first explosion factory clears follow-particles. Every Update, including inactive bubbles, traverses actual retained root statuses. While follow-particles bit0 is set, each updating root is positioned at the current bubble position first. The oracle status schedule is supplied and must never become gameplay lifetime physics.

During lift, shadow is computed each draw from original input origin plus half the launch-to-current vertical difference; after lift it uses the evolving shadow position.
