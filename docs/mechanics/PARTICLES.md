The old reconstruction drew all balls, then every broad strip, then all cores. That incorrectly prevented later broad ink from attenuating earlier additive ink. The new working renderer keeps per-effect sequences. For each bolt it rasterizes the broad strip's remaining-light product R into a cropped reusable target, multiplies the main framebuffer by R, adds1-R, then draws the core.
