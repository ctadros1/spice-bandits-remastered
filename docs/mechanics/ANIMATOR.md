# Original animator clocks, frame blending and offsets

Current package is R123: the recovered creep clocks now also feed an ordered additive hit pass. See [hit integration, native verification and remaining limits](CREEP_HIT.md). Historical clock evidence below remains scoped to R118–R119.

R116–R117 restores bounded rendering behavior from the preserved1.14 executable. Full offline fidelity remains incomplete.

## Original code and scope

- `CAnimProcessor` constructor`0x10ef20`, `PlayAnimation0x10f0cc`, `Update0x10f3a0` and `Render0x10f54c` execute in isolated ARM reference probes. Animation/group records and zeroed storage are supplied. Exact string matching and GetTickCount are explicit stubs; no original Init/resource loader, room clock producer, window or GPU executes.
- Ordinary frame clocks use separate float32 division/product/addition steps. Loops reset phase/index to0 when overflowing, discarding the remainder. Nonloops retain the last frame and finish. A zero playback multiplier retains the phase.
- Alpha animations use a supplied monotonic clock and original Interpolate. Loop endpoints reverse direction, starting a fresh interval on the following update. Same-name Play clears the finished flag without resetting phase or alpha timers; changing names resets the alpha timer, and resets ordinary phase only when the animator's reset-on-change flag is set.
- `alpha_between_frame` compares the adjacent frames' atlas X/Y and final offsets. It does **not** compare their widths/heights or texture identity. Equal keys submit only the current frame with white modulation. Different keys submit current then next; for fractional progress p, the current opacity is1−clamp(2p−1,0,1), and next opacity is min(1,2p). Both raw RGBA colors use those values. This overlaps opaque portions through the midpoint rather than using a conventional crossfade. It also overrides the caller's tint/internal opacity. Tests retain the raw GL arguments; conversion to the decoded straight-alpha rendering path is separate.

## Sprite geometry

Full `CAnimFrames::AddFrame0x10eb58` combines animation and individual frame offsets, then adds0.5 to each odd-size axis. `AddFrameStack0x10e8d0` uses its supplied absolute offsets, with the same parity correction. The importer now marks individual added frames, allowing the shared frame resolver to distinguish them from stacks and regular rows. Frame crops, rotation/flips, source atlas coordinates and original proportions are retained. The normal and raw-premultiplied screen paths share this geometry.

The stack reference executes the original generation, wrap, reversal, vector insertion and frame-count prefix through`0x10eaf2`. Allocation/vector operations use bounded reserved storage. Cleanup is deliberately outside that probe: attempting its predicated BLX deallocation import under Unicorn returned to address0. Initial full-cleanup and diagnostic attempts are retained. This is not a claim of complete original allocator/unwind behavior. The frame-generation loop is executed without substituting its arithmetic. The first decompile selection supplied0x-prefixed addresses and selected zero functions; corrected exact addresses produced the retained source files.

The runtime unit checks all2,389 imported frame offsets/keys against these field rules. This does not establish complete original XML parsing, frame-option/combined-frame behavior, quad center/rotation handling, texture allocation, sampling or device raster equivalence.

The game retains clocks for mine Builded lights, portal Blue/Red, nuke Blinking lights at their authored8FPS and affected animated tower Idle art. The tower-info icon retains its direct Idle frame0 path: original RenderTowerInfoPanel0xf2e60 calls GetAnimationFrame, so it must not inherit the full animator's white modulation override. Portal clocks stay stopped until the original opening-stage Play call.4,420 extra assertions bind that resume guard to the existing original portal call traces; the portal unit now has42,580 checks.

A rendered process epoch advances an owned clock once; repeated QA readbacks retain that frame. Pausing holds the clock. This is the Godot bridge for the normal one-update/one-render flow, not proof of the original whole-room scheduling, culling or arbitrary extra Render calls. Frame blending is emitted in place in the owner's current canvas pass. There is no global layer of blended overlays.
