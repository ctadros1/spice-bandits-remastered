# Original target selection

Baseline: decrypted1.14 GetNearestCreep0xfb9b0, CTower::Update0xe53b4, CCreep::UpdatePosition0x7d108, CCreep constructor0x78374 and CRoom::InitSources0xcf074. Original SHA256 is recorded in the fixture. Ghidra pseudocode was reviewed against ARM instructions; the Strongest conversion is explicit at0xfbd2a.

For a single target, the routine walks the creep list in its existing order. Eligible enemies must have positive HP, states other than2/3, the requested resource ground/air class, a different owner from the tower, and target-owner zero or the tower's owner. Gravity additionally excludes state5. It compares squared distance between the tower's integer cell and the creep's interpolated fractional grid coordinates. Only a new strict distance minimum that passes the range ellipse is appended to the candidate list. The first limit is100000000. This is a record-minimum list, not every in-range enemy or merely the final nearest enemy.

Fastest (also the empty mode string) selects the largest effective speed, starting at zero. Strongest compares currentf32 HP to an integer threshold and truncates that threshold after accepting a candidate. Consequently20.2 can replace20.7 when the previous threshold has become20. Weakest keeps its HP threshold asf32. All comparisons are strict. An unknown nonempty mode returns no target. The area-output path collects every eligible in-range enemy; Gravity retains the single-target path even if an output vector was supplied.

The fixture executes164 original ARM cases: all24 permutations of a four-enemy list under four modes, and additional status, class, owner, target-owner, health, Gravity and area-output cases. Ellipse membership, vector allocation/append and exact string matching are controlled stubs. Selection is captured fromr4 before temporary-vector cleanup at0xfbd7e/0xfbd88. This is a bounded original-function oracle, not a running original iOS app, target-retention oracle or original rendering comparison.

The reviewed script helper remains the reference; the C++ hot-path helper used by the simulation independently passes all164 original ARM fixtures. Source ownership comes from the original source neutrality/target fields; all348 source records in the recovered nonempty offline configurations contain zero for both. Local towers belong to player1. Aim checks use the authored ground/air class, including a ground unit temporarily levitated by Gravity. Fractional grid position remains separate from logical pixels and the drawn rounded-corner position. Existing zero-speed renderer fixtures use Strongest, since native Fastest correctly selects no zero-speed target.

Remaining comparisons include every retention/physical-range edge, changing ownership in online modes, the native whole-room variable-delta update, and the original global random stream. Offline source/owner data coverage does not prove multiplayer filters or escort behavior.
